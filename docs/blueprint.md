# **App Name**: Mi Billetera Vehicular

## Core Features:

- Vehicle Profile Creation: Allow users to input all the details from their vehicle's property card (front and back), SOAT, and Tecnomecanica documents. Fields include license number, owner details, vehicle specifications, etc.
- Document Storage: Store digital copies of SOAT, Tecnomecanica, vehicle manual, and ficha tecnica.
- Maintenance Tracker: Track current mileage, create a visual bar indicator for vehicle usage, and set reminders for upcoming revisions, tire changes, etc.
- Data simulation: Use collected user information from the property card to calculate estimated maintenance costs based on make, model, and usage and suggest nearby mechanic shops using the tool.

## Style Guidelines:

- Primary color: Deep blue (#2E3192) to convey trust and reliability.
- Background color: Light blue (#D4E0ED), a desaturated version of the primary for a clean interface.
- Accent color: A vibrant purple (#736CED) to highlight interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, provides a modern, neutral look suitable for both headlines and body text.
- Use clear, simple icons for navigation and to represent different vehicle documents and maintenance tasks.
- Implement a clean, card-based layout for each vehicle and document, ensuring easy readability and navigation.
- Use subtle transitions and animations to provide feedback on user interactions, such as saving data or setting reminders.
